# Kenney assets (CC0)

Models and textures from kenney.nl, Creative Commons Zero (public domain). Each folder keeps its original `License.txt`.

| folder | contents |
|---|---|
| `nature-kit/` | 329 GLB models |
| `fantasy-town-kit/` | 167 GLB models |
| `car-kit/` | 50 GLB models |
| `castle-kit/` | 76 GLB models |
| `pirate-kit/` | 72 GLB models |
| `train-kit/` | 103 GLB models |
| `watercraft-pack/` | 46 GLB models |
| `retro-textures-fantasy/` | 117 PNG textures |

## Notes
- Each kit has its own folder because file names repeat between kits (for example `grass.glb` is in both `nature-kit` and `pirate-kit`) and each kit has its own `Textures/colormap.png`.
- Keep `Textures/` next to the `.glb` files: the models load `Textures/colormap.png` by relative path. Nature Kit models need no texture file.
- Only the GLB models, their textures and the licences are included (no previews, OBJ, FBX or other formats).
